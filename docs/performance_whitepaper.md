## 一、项目概述

本项目是一个 C++ 高性能基础库，包含 5 个核心模块，全部通过 pybind11 暴露给 Python。

| 模块 | 功能 |
|------|------|
| IntArray | RAII 内存管理，支持拷贝/移动语义 |
| ThreadPool | 线程池，`submit()` 返回 `std::future` |
| ThreadSafeStack | 线程安全栈（mutex + 条件变量） |
| Tokenizer | 中文分词器（最大匹配算法） |
| Calculator | 表达式求值（递归下降解析器） |
| Cosine | 余弦相似度（循环展开） |

## 二、性能数据

### 2.1 IntArray

| 操作 | 大小 | 耗时 |
|------|------|------|
| 深拷贝 | 1M | ~256 μs |
| 移动 | 1M | ~1.1 ms |

**结论**：移动语义避免内存分配，适合大数组传递。

### 2.2 ThreadPool

| 线程数 | 10M 词耗时 | 加速比 |
|--------|-----------|--------|
| 1 | 130 ms | 1.00x |
| 2 | 79 ms | 1.65x |
| 4 | 43 ms | 3.02x |

**结论**：4 线程接近线性加速（3.02x / 4 = 75.5% 效率）。

### 2.3 Tokenizer

| 指标 | 数值 |
|------|------|
| 吞吐量 | **14.04 MiB/s** |
| 测试文本 | 57 万字节 |
| 分词结果 | 9 万词 |

**结论**：满足 10 万字吞吐量要求（>5 MB/s）。

### 2.4 Cosine Similarity

| 维度 | C++ (μs) | Python (μs) | 加速比 |
|------|----------|-------------|--------|
| 128 | 1 | 10 | 10x |
| 1024 | 6 | 50 | 8x |
| 4096 | 20 | 250 | 12x |

**结论**：C++ 比 Python 快 8-12 倍。

### 2.5 Calculator

| 指标 | 数值 |
|------|------|
| 单次求值 | 554 ns |
| 支持 | 加减乘除、括号、负数、小数 |

**结论**：单次解析 < 1μs，满足实时需求。

### 2.6 ThreadSafeStack

| 操作 | 耗时 |
|------|------|
| Push + Pop | 59.7 ns |

**结论**：极快，适合高并发场景。
